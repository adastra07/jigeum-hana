# 지금 하나 — 요청 사항 및 업데이트 내역

작성 기준: 2026년 11월 22일 · 최신 구현: **v1.24 / versionCode 26**

이 문서는 개발 인수인계 요청부터 화면 조정, 타이머·스탑워치, 분류·글자 크기 설정까지 사용자의 요청과 실제 반영 내역을 하나로 정리한 기록이다. 대화의 요청 사항을 저장소의 소스·커밋·빌드 결과와 대조했다. 중간에 바뀐 요구는 최종 요청을 우선하며, 구현 완료와 실제 기기 검증은 구분한다.

## 1. 프로젝트 목표와 작업 원칙

- **앱 이름:** 지금 하나 / Jigeum Hana.
- **핵심 목적:** 할 일을 기록하고, 지금 집중할 항목 하나를 선택하여 집중한다.
- **방향:** 가벼운 Android 앱, 빠른 실행, 직관적인 조작, 간결한 화면. 불필요한 기능을 대량 추가하지 않는다.
- **저장소:** [adastra07/jigeum-hana](https://github.com/adastra07/jigeum-hana). 기존 `android-mini-apps` 저장소는 작업 대상에서 제외한다.
- **이전 방식:** Windows의 원본 소스를 확보하기 전, 기존 APK를 분석하여 Kotlin 네이티브 프로젝트로 재구성한다. 확인하지 않은 클래스·동작을 사실로 단정하지 않는다.
- **클라우드 개발:** 전체 소스, Gradle 설정, README, .gitignore, GitHub Actions를 저장소에 두고 노트북 없이 APK를 빌드·다운로드할 수 있게 한다.
- **검증:** 빌드 성공과 실제 기기의 동작 검증을 구분하고, 막힌 원인과 필요한 조치를 구체적으로 알린다.
- **전달 방식:** 현재는 작업 완료 후 APK 파일을 직접 제공한다. 다른 사람에게 공유할 링크는 사용자가 요청할 때 따로 만든다.

## 2. 기존 APK 분석과 재구성

입력 파일은 `jigeum-hana-debug (2).apk`이며, 정적 분석에서 앱 버전 1.2 / versionCode 3, 패키지 `com.adastra.focuswallpaper`, DEX 3개, Kotlin metadata와 기본 Android Views 구조를 확인했다. Manifest·DEX·리소스 분석 및 일부 DEX 명령어 추가 확인을 바탕으로 동등한 동작을 다시 작성했다.

확인한 기존 기능은 할 일 추가·편집·삭제·완료 체크, 집중 선택·시작, 시간 프리셋 5/25/60분, 일시정지·재개·종료, 진행 및 완료 알림, 홈·잠금화면에 현재 할 일 적용, 배경 미리보기 등이다. 완료 체크만으로 타이머가 자동 종료되거나 항목이 자동 완료되는 구조는 아니다.

기존 데이터 형식과의 연속성을 위해 SharedPreferences `focus`와 JSON 저장을 유지했다. UI는 Compose로 바꾸지 않고 기존 구조에 가까운 기본 Android Views를 선택했다. Room/DataStore로의 전환은 하지 않았다.

원본 서명 키는 APK에서 복원할 수 없으므로 최초 Windows 설치본 위의 업데이트 및 데이터 유지 호환성은 보장하지 않는다. 분석 세부 근거와 최초 기기 점검표는 [APK_ANALYSIS.md](APK_ANALYSIS.md)에 있다.

## 3. 사용자 요청과 현재 반영 상태

**v1.20 정정:** v1.19의 ‘일반 설정에 목록 순서 배치’는 의도와 달랐다. 최종 위치는 체크리스트 상단의 목록 이름을 길게 눌러 여는 목록 설정창이다. 길게 누른 목록을 가운데에 고정하고 화살표를 여러 번 눌러 이동한다. 이름 변경·분류 삭제도 같은 창에 유지하며 일반 설정에서는 제거했다. 순서 행 최소 높이는 36dp로 줄이고 긴 이름·큰 글자에는 확장한다. 이하 v1.19 설명은 중간 구현의 기록이다.

**v1.19 후속 조정:** 목록 순서를 바꾸는 기능은 설정의 전용 행으로 추가했다. ‘왼쪽 화살표 · 왼쪽 이웃 · 선택 목록 · 오른쪽 이웃 · 오른쪽 화살표’로 표시하고 화살표를 누를 때 선택 목록을 한 칸씩 옮긴다. 가운데 이름으로 목록을 선택하며 이웃 이름을 눌러 선택을 옮길 수도 있다. 끝에서는 없는 쪽 이름·화살표를 숨긴다. 즉시 저장하고 목록 ID·할 일·기록과 목록 안의 항목 정렬은 유지한다. 기존 체크리스트 화면의 길게 누르기 이름 변경·삭제 동작은 그대로다. 처음 제안한 구분자 터치나 목록 드래그 대신 최종 화살표 방식을 적용했다.

**v1.18 후속 조정:** 프리셋은 저장 버튼 없이 입력 즉시 자동 저장한다. 입력란별로 유효한 0~180분만 반영하며 빈칸·범위 밖 값은 이전 저장값을 유지한다. 프리셋 저장 버튼 및 저장 토스트는 제거했다.

**v1.16 후속 조정:** 아래의 10단계·최대 21·‘마지막과 같이’는 도입 당시 기록이다. 현재 글자 크기는 12~20의 **9단계**이고 중앙 기본값은 16이다. 미리보기 문구는 `ABC abc 123 가나다`, 마지막 방식을 따르는 버튼명은 **최근 설정**이다. 배경화면은 알림보다 위에 있으며, 기본 집중 방식의 세 버튼은 같은 너비·기본 최소 높이 32dp로 조정했다. 큰 글자에서는 텍스트와 상자의 높이가 함께 늘어난다. 이동 항목은 반투명하고 제목 터치의 초록 효과는 행 전체에 표시한다.

### 3.1 체크리스트와 기본 화면

| 요청 | 현재 반영 상태 |
|---|---|
| 상단 안내 박스 제거 | 제거하고 목록과 현재 집중 항목 중심으로 구성 |
| 각 항목 오른쪽에 삭제 ×와 집중 시작 버튼 | ×는 휴지통 이동, 타이머 항목은 시간 숫자만 표시하는 시작 버튼 제공 |
| 별도의 ‘○○분 집중’ 멘트 제거 | 반복 안내를 줄이고 항목 이름·시간·조작 중심으로 정리 |
| 버튼이 이미지처럼 보이는 느낌과 잘리는 그림자 개선 | 그림자 없는 평평한 버튼과 벡터 아이콘 사용 |
| 큰 원형 시간 버튼을 작은 빈 직사각형으로 변경 | 회색 테두리 직사각형, ×와 어울리는 회색 적용 |
| 항목 간 상하 간격 축소 | 기본 최소 행 높이 48dp로 조정. 긴 제목에는 필요한 높이 사용 |
| 현재 집중 화면을 위로 올리고 작게 표시 | 모든 하단 탭의 상단에 공통 집중 표시 배치 |
| 타이머를 항목 이름 오른쪽에 정렬 | 제목은 왼쪽, 시간과 조작은 오른쪽에 표시 |
| 모든 탭의 집중 타이머를 박스로 구분 | 흰 배경과 연한 테두리의 작은 박스로 표시 |
| 길게 누른 뒤 끌어 항목 순서 변경 | 이름을 길게 누르고 위아래로 이동. 분류별 순서 저장, 가장자리 자동 스크롤, 목록 밖에 놓으면 취소 |

짧게 누르면 기존처럼 할 일 편집창이 열린다. 순서 변경은 다른 분류·휴지통 항목과 항목별 시간 기록을 보존하도록 구현했다.

### 3.2 분류, 하단 탭, 휴지통

| 요청 | 현재 반영 상태 |
|---|---|
| 참고 화면처럼 상단에 여러 분류 탭 | 가로 스크롤 분류 탭과 추가 + 제공 |
| 분류 편집 | 체크리스트의 분류 이름을 길게 눌러 이름 변경·삭제. 기본 분류는 이름 변경 가능 |
| 설정의 분류 관리는 제거 | 분류 관리는 체크리스트 탭으로 모음 |
| 편집창의 분류 선택을 버튼 외형 없는 이름 모음으로 변경 | `오늘 / 공부 / …`처럼 슬래시로 구분하고 가로 스크롤. 선택한 이름은 강조. 취소선 표현이 아님 |
| 하단에서 탭 이동 | 체크리스트·휴지통·설정의 고정 하단 바 제공 |
| 탭 바 높이·위 여백 조정 | 높이 80dp. 후속 요청에 따라 아이콘과 라벨을 조금 내려 상단에 여유 확보 |
| 항목 삭제 시 묻지 말고 휴지통으로 이동 | 일반 × 삭제는 확인 없이 이동 |
| 복원은 글자 대신 아이콘 | 휴지통에 복원 아이콘 제공 |
| 휴지통 비우기와 연한 색 사용 | 차분한 회색의 비우기 제공. 비우기·개별 영구 삭제는 확인 후 실행 |

분류를 삭제하면 해당 분류의 활성 항목과 휴지통 항목은 기본 분류로 이동한다. 휴지통 자동 삭제는 없다. 일반 삭제의 ‘확인 없이 이동’과 데이터가 사라지는 영구 삭제의 확인은 구분한다.

### 3.3 집중 시간, 선택과 해제

| 요청 | 현재 반영 상태 |
|---|---|
| 시간 프리셋 5/25/60분 변경 가능 | 설정에서 3개 프리셋 편집·저장. 현재 각 0~180분 허용 |
| 편집창의 시간 선택이 빽빽하지 않게 | 직접 입력과 프리셋을 두 줄로 분리하고 간격·높이 조정 |
| 프리셋 설정의 ‘분’은 숫자 오른쪽에 | 숫자 입력란 오른쪽에 단위 표시 |
| 새 할 일은 마지막 설정 시간을 기본으로 | 마지막으로 저장·선택·시작한 시간과 방식을 기억하도록 구현한 뒤, v1.14에서 기본 방식 선택 설정으로 확장 |
| ‘집중 시작’이 너무 진하므로 ‘집중 선택’과 균형 조정 | 두 버튼을 연한 회녹색 계열로 조정 |
| 재생·일시정지 아이콘 굵기·크기 조정 | 채워진 벡터로 정리 후, 과하게 굵고 큰 부분을 축소. 시간의 우측 정렬 유지 |
| 0분이면 타이머 기능과 시작 버튼 제거 | 목록의 시간 시작 버튼과 편집창의 시작 버튼 숨김. 집중 선택은 가능 |
| 직접 입력 오른쪽에 작은 회색 ‘미지정’ | 0분으로 설정하는 버튼 제공 |
| 집중 해제 기능 | 선택 항목의 편집창, 상단 ×, 알림에서 해제. 0분 항목도 편집창에서 해제 가능 |
| 설정에서 기본 집중 방식 선택 | ‘미지정 / 스탑워치 / 마지막과 같이’ 제공. 최초 기본값은 기존 동작과 같은 ‘마지막과 같이’ |

기본 방식 설정은 **새 항목**에 적용한다. 기존 항목의 시간·방식은 바꾸지 않는다. 실행 중인 항목을 0분으로 바꾸면 해당 타이머와 완료 알람을 종료하며 다른 항목의 타이머를 임의로 종료하지 않는다.

### 3.4 항목별 스탑워치

- 직접 입력란 오른쪽의 작은 회색 ‘스탑워치’로 선택한다.
- 선택 시 ‘집중 시작’ 대신 ‘스탑워치 시작’을 표시하고, 시간 제한 없이 경과 시간을 측정한다.
- 체크리스트의 스탑워치 항목에는 시간 숫자 대신 스탑워치 아이콘을 표시한다.
- 경과 시간은 각 항목별로 저장한다. 일시정지·집중 해제·다른 항목 전환 뒤 다시 선택하면 저장한 시간에서 이어간다.
- 실행 중 일시정지 왼쪽에 재시작 아이콘을 둔다. 일시정지·×와 비슷한 크기와 굵기로 맞췄다.
- 재시작은 해당 항목의 기록만 0으로 초기화한 뒤 즉시 측정을 계속한다.
- 숫자 직접 입력 또는 시간 프리셋 선택 시 타이머 방식으로 돌아간다.
- 스탑워치는 완료 시각이 없으므로 완료 알람을 예약하지 않는다. 알림에서 재시작·일시정지·재개·집중 해제를 제공한다.

### 3.5 배경화면과 설정 화면

| 요청 | 현재 반영 상태 |
|---|---|
| 배경 자동 변경을 켜고 끄기 | 설정의 자동 변경 스위치 제공 |
| 파스텔 중심의 배경색 지정 | 색상 팔레트 제공 후 10개로 확대, 5열 2행 배치 |
| 색상 이름 제거 | 화면에는 색상만 표시. 접근성용 이름은 유지 |
| 설명은 제목 오른쪽의 동그란 i 아이콘으로 | 설정 제목 오른쪽 ⓘ를 눌러 안내 확인 |
| 배경 미리보기도 설명 안으로 | 배경화면 ⓘ 안내에서 미리보기로 이동 |
| 설정 섹션마다 약간의 간격 | 섹션 사이 8dp 간격 적용 |
| 가능하면 스크롤 없이 설정 확인 | 기존 설정은 간격을 줄여 정리. 새 설정 추가·큰 글자·작은 화면에서는 스크롤 허용 |
| 프리셋 저장 멘트는 ‘저장했습니다’ | 해당 문구로 통일하고 다른 안내도 간결한 표현으로 정리 |
| 집중 해제 시 이전 배경 저장·복원 검토 | 후속 요청인 ‘일단 멘트만 제거’를 적용. 이전 사진 복원은 구현하지 않음 |
| 글자 크기 10단계와 초기화 | 본문 기준 12~21의 10단계, 슬라이더와 미리보기 제공. 초기화 시 16 |
| 크기 수치는 시작·중간·끝 아래에만 작고 회색으로 | 슬라이더 하단에 12·16·21만 표시 |

글자 크기는 제목·본문·버튼·입력창에 비례하여 적용하고 설정을 저장한다. Android의 sp 기반이며 휴대전화 글자 크기 설정도 반영한다. 큰 글자에서 긴 조작 문구가 잘리지 않도록 일부 버튼의 높이는 내용에 맞춰 늘어날 수 있게 했다.

배경 자동 변경을 끄면 자동 적용을 멈추며 미리보기에서 수동 적용은 가능하다. 색상 선택은 다음 적용부터 반영된다. 집중 해제 시 앱이 적용한 배경의 할 일 문구를 지우고 **적용 당시 배경색은 남긴다**. 기존 사진을 되돌리거나 배경 설정 자체를 초기화하는 동작은 아니다.

- **잠금 해제 시 상기 화면:** 최초 요청부터 초기 버전에서 제외. 시스템 제한과 사용 경험 검토 후 판단한다.
- **이전 배경 사진 저장·복원:** 후속 요청에 따라 현재는 문구만 제거한다. 사진 복원은 구현하지 않았다.
- **기존 Windows 설치본 데이터 이전:** 원본 키·실제 설치 환경 확보 전까지 호환성을 약속하지 않는다. 기존 앱 삭제 시 로컬 데이터도 삭제될 수 있다.
- **장기 배포용 서명:** 디버그 키 캐시와 별도의 안정적인 관리 방식은 아직 후속 과제다.
- **강제 중지·권한 제한:** Android에서 앱을 강제 중지하면 알람·수신이 차단될 수 있어 다시 열어야 한다. 정확한 알람을 허용하지 않으면 절전 중 완료 알림이 지연될 수 있다. 잠금화면 내용 표시는 기기 설정을 따른다.

1. 이 문서의 현재 상태를 출발점으로 삼고, 새 요청이 기존 요구를 바꾸면 최종 결정을 명시한다.

4. 코드 수정 후 변경에 맞는 검증을 수행하고 빌드 결과와 기기 확인 여부를 따로 보고한다.
5. 기본 전달물은 APK 파일이다. 공개 배포 링크는 사용자가 공유를 요청할 때 준비한다.


## 8. 캘린더 확장 — v1.21

사진을 참고하여 월간 달력 → 날짜별 목록 창 → 메모 편집기로 이동한다. 같은 날짜의 메모 여러 개, 캘린더 전용 분류, 날짜·시간·기간을 이번 범위로 선택했다. 처음의 ‘날짜 제목 고정’ 설명은 정정되었으며 실제 제목은 자유 입력이고 상단 날짜만 참고용이다. 일반 텍스트부터 시작하고 D 아이콘은 제외한다.

후속 결정은 분류별 색상(분류 편집 시 전체 적용), 기존 휴지통 안의 할 일/캘린더 구분 탭, 자동 저장이다. 메모 편집 위 색 동그라미는 해당 분류 편집으로 연결하며 일괄 색상 변경을 적용한다. 캘린더 상단 분류는 길게 눌러 이름·색상·순서를 관리하고, 삭제 시 메모를 미분류로 옮긴다.

월 이동·오늘·날짜 선택, 날짜별 이전/다음, 제목·내용 검색, 날짜별 추가, 종일·시간 지정·여러 날 기간을 구현한다. 여러 날 일정은 시작·종료 날짜를 포함한다. 자동 저장은 300ms 대기 후, 화면 이탈 시에는 대기 없이 실행한다. 빈 새 메모는 만들지 않는다. 캘린더 휴지통 비우기는 할 일 휴지통에 영향을 주지 않는다.

향후 일반 노트를 위해 자유 제목·본문을 갖는 공통 Note, 선택적 NoteSchedule, 별도 SQLite 저장소, 공통 편집 Activity를 준비했다. 기존 체크리스트·타이머 저장소는 변경하지 않는다. 서식·실행 취소/다시 실행, 반복·알림, D 아이콘과 일반 노트 탭은 후속 범위다. 캘린더 첫 버전의 실제 기기 화면·키보드·절전 복원은 별도 확인이 필요하다.


## 9. 캘린더 공간·조작 조정 — v1.22

사용자 피드백에 따라 달력 표면의 좌우 밀기로 월 이동을 추가하고, 추가 버튼은 캘린더 스크롤 내용과 독립된 오른쪽 아래 원형 오버레이로 변경했다. 스크롤 중에도 버튼 위치를 유지하고 하단 안전 여백과 그림자 여백을 확보한다. 버튼은 레이아웃의 별도 행이 아니다.

상하 길이가 길다는 지적에 맞춰 별도 오늘·검색 행을 없애 월 표시 줄에 통합하고, 상단 제목 여백·요일 높이·날짜 칸 높이를 축소했다. 남은 실제 화면 높이를 기준으로 날짜 칸을 48~72dp로 계산하며, 메모는 공간만큼 표시하고 초과 개수는 날짜별 목록에서 확인한다. 짧은 터치·세로 움직임은 월 이동과 구분하며, 월을 옮긴 뒤 추가하는 일정의 날짜가 이전 달에 남지 않도록 선택 날짜도 함께 맞춘다.
