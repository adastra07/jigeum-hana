# 지금 하나 · Jigeum Hana

체크리스트에서 지금 할 일 하나를 선택하고 집중하는 가벼운 Kotlin Android 앱.
기존 1.2 APK를 정적 분석하여 Kotlin 소스로 재구성한 첫 클라우드 버전입니다.

## 1.12 항목별 스탑워치

시간 직접 입력란 오른쪽에 작은 회색 ‘미지정’과 ‘스탑워치’를 추가했습니다. 미지정은 0분이며 숫자를 입력하거나 프리셋을 선택하면 다시 타이머 모드가 됩니다.
스탑워치는 항목별 경과 시간을 저장하고 재선택 시 이어서 측정합니다. 일시정지·집중 해제·항목 전환·앱 재실행 후에도 기록을 유지합니다. 편집창에서 저장된 시간을 확인할 수 있습니다.
스탑워치 작동 중에는 일시정지 왼쪽에 재시작 아이콘을 표시합니다. 재시작은 해당 항목의 기록을 0으로 초기화하고 즉시 측정을 계속합니다. 알림에서도 재시작·일시정지·재개·집중 해제가 가능합니다.
스탑워치는 완료 알람을 예약하지 않으며, 화면 잠금·절전 중에도 시스템 시간 기준으로 계산합니다. 같은 부팅에서는 elapsedRealtime을 사용하여 수동 시계 변경의 영향을 받지 않습니다. 재부팅 시 저장한 시각 기준으로 이어집니다.
기존 타이머·0분 항목은 변경 없이 읽습니다. 타이머 상태와 항목 기록은 일시정지/전환 시 한 번에 저장합니다. 기존 항목을 타이머로 바꿔도 스탑워치 기록은 보존되며 재시작에서만 0으로 만듭니다.

## 1.11 집중 해제 시 배경 문구 지우기

앱이 적용한 집중 배경은 집중 해제 시 글자를 지우고 적용 당시의 단색 배경만 남깁니다. 상단 ×, 항목 편집창, 알림의 집중 해제에서 동일하게 동작합니다. 기존 배경 사진을 복원하는 기능은 아닙니다.
자동 변경을 끄고 앱으로 배경을 적용한 적이 없으면 배경을 덮어쓰지 않습니다. 앱에서 수동으로 적용한 집중 배경도 해제할 수 있습니다. 이전 버전에서 선택된 항목이 있고 자동 변경이 켜져 있다면 최초 해제 시 해당 배경색으로 지웁니다.
배경 적용과 해제를 같은 작업 큐에서 처리하여 해제 직후 이전 문구가 다시 적용되는 것을 방지합니다. 새 집중이 선택되면 이전 해제 요청이 새 배경을 지우지 않습니다.

## 1.10 집중 해제

현재 선택한 항목을 열면 ‘집중 선택’ 대신 ‘집중 해제’가 표시됩니다. 0분 항목도 같은 방법으로 해제합니다.
상단 집중 표시의 ×와 알림의 집중 해제 버튼도 타이머·완료 알람·선택 표시를 함께 해제합니다. 항목 내용과 완료 여부는 그대로 유지합니다.

## 1.9 타이머 없는 할 일

집중 시간을 0분으로 저장하면 체크리스트의 시간 시작 버튼과 편집창의 집중 시작 버튼을 숨깁니다. 집중 선택과 배경화면 적용은 계속 사용할 수 있습니다.
프리셋에도 0분을 저장할 수 있으며 새 항목의 기본 시간에도 기억됩니다. 실행 중인 항목을 0분으로 저장하면 해당 타이머와 완료 알람을 종료합니다. 다른 항목의 타이머는 유지합니다.
0분 항목은 앱 재실행·분류 이동·휴지통 복원 후에도 그대로 보존합니다.

## 1.8.1 마무리 조정

타이머의 우측 정렬과 버튼 터치 영역을 유지하면서 일시정지/재개 아이콘을 작고 가늘게 조정했습니다. 설정 섹션 사이에는 8dp 간격을 추가했습니다. 하단 탭 바의 아이콘과 라벨을 약 5dp 아래로 옮겨 아이콘 위에 여유를 두었습니다.

## 1.7 간결한 설정 화면

재개/일시정지 버튼을 채워진 벡터 아이콘으로 변경했습니다. 하단 탭 바 높이를 80dp로 늘리고 아이콘·라벨 간격을 확보했습니다.
설정의 분류 관리는 제거하고 체크리스트 탭에서 관리합니다. 프리셋의 분 단위는 입력란 오른쪽에 배치했습니다.
각 설정 제목 오른쪽의 ⓘ에서 설명을 확인하며 배경 미리보기도 배경화면 ⓘ 안에 있습니다.
이름 없는 10개 색상은 5열 2행으로 배치합니다(접근성 이름은 유지). 설정의 여백을 줄여 기본 글꼴의 일반 세로 화면에서 한눈에 확인하도록 구성했습니다. 작은 화면·큰 글꼴·키보드 표시 상태에서는 스크롤이 가능합니다.

## 1.6 편의 기능과 색상

- 모든 탭에 표시되는 집중 타이머를 연한 테두리 박스로 구분했습니다.
- 설정 → 배경화면에서 자동 변경을 켜거나 끄고 파스텔 6종·흰색·검정 중 배경색을 지정합니다. 밝은 배경은 어두운 글씨, 검정 배경은 흰 글씨로 표시합니다. 기본색은 민트입니다.
- 자동 변경을 끈 상태에서도 미리보기의 적용 버튼으로 수동 적용할 수 있습니다. 색 선택은 다음 자동/수동 적용부터 반영됩니다.
- 새 할 일은 마지막으로 저장·선택·시작한 할 일의 시간을 기억합니다. 아직 기록이 없으면 기존 두 번째 프리셋을 사용합니다.
- 시간 입력란과 프리셋을 두 줄로 분리하고 집중 선택/시작 버튼을 연한 회녹색으로 맞췄습니다.
- 프리셋 저장 안내를 ‘저장했습니다’로 통일하고 휴지통 복원은 아이콘으로 표시합니다.
- 휴지통 상단 ‘휴지통 비우기’는 확인 후 휴지통 항목만 영구 삭제합니다. 활성 목록과 다른 분류는 유지합니다.

## 1.5 화면과 분류

- 모든 화면 버튼을 그림자 없는 평평한 스타일로 변경. 항목의 시작 버튼은 작은 회색 테두리 직사각형이며 숫자만 표시합니다.
- 집중 중 표시를 상단에 작게 배치하고 항목 이름 오른쪽에 남은 시간·일시정지/종료를 표시합니다.
- 하단 고정 바에서 체크리스트·휴지통·설정을 이동합니다.
- 상단 분류 탭의 +로 분류를 추가하고 길게 눌러 이름 변경/분류 삭제가 가능합니다. 편집창에서 다른 분류로 항목을 옮길 수 있습니다.
- ×는 확인 없이 휴지통으로 이동합니다. 휴지통에서 원래 분류로 복원하거나 확인 후 영구 삭제할 수 있습니다. 자동 삭제는 없습니다.
- 설정에서 3개 시간 프리셋(각각 1~180분)을 저장합니다. 새 할 일은 두 번째 프리셋을 기본값으로 사용하며, 이미 저장된 항목의 시간은 유지합니다.
- 기존 할 일은 기본 분류로 읽으며 목록과 시간·완료 상태를 보존합니다. 분류 삭제 시 그 안의 항목과 휴지통 항목을 기본 분류로 옮깁니다.

## 기능

- 할 일 추가·편집·삭제·완료 체크, 할 일별 1~180분 설정(기본 25분, 5/25/60분 바로 선택)
- 집중 선택·시작, 일시정지·재개·종료, 프로세스 재생성 후 종료 시각으로 복원
- 시스템 알람으로 완료 알림, 잠금화면 진행 알림과 카운트다운·조작 버튼
- 자동 변경이 켜져 있으면 선택/시작 시 지정한 배경색으로 할 일을 홈·잠금 배경화면에 적용, 미리보기 및 재적용
- 로컬 저장만 사용, 인터넷·계정·서버 없음

## 휴대전화에서 APK 받기

1. 저장소 **Actions → Android Debug APK**에서 최신 성공 실행을 엽니다.
2. **Artifacts → jigeum-hana-debug-실행번호** ZIP을 다운로드합니다(GitHub 로그인 필요).
3. 압축을 풀고 `app-debug.apk`를 설치합니다.
4. 처음 집중을 시작할 때 알림을 허용합니다. 절전 중 정확한 완료 알림이 필요하면 앱 **설정 → 정확한 완료 알람 허용**을 켭니다.

소스를 main에 반영하면 자동 빌드됩니다. Actions의 **Run workflow**로 수동 재빌드도 가능합니다. APK는 30일간 보관됩니다.

## 기존 설치본과 서명

패키지명 `com.adastra.focuswallpaper`, SharedPreferences `focus` 및 JSON 필드 이름을 보존했습니다.
그러나 APK에서 기존 개인 서명 키를 복구할 수 없으므로 **기존 설치본 위에 업데이트 설치하거나 데이터를 유지할 수 있다고 보장하지 않습니다.**
서명이 다르면 설치가 거부됩니다. 기존 앱을 삭제하면 목록도 삭제되므로 필요한 항목을 먼저 기록하세요.
기존 Windows 개발 환경의 debug.keystore를 나중에 확보하면 서명 일치 여부를 별도로 확인할 수 있습니다.
CI 디버그 키는 Actions 캐시로 재사용하지만 캐시가 만료/삭제되면 바뀔 수 있습니다. 배포용 안정적인 서명 관리는 후속 작업입니다.
APK와 서명 키는 저장소에 커밋하지 않습니다.

## 빌드

JDK 17, Android SDK platform 35/build-tools 35.0.0, Gradle Wrapper 8.13.
Android Gradle Plugin 8.9.2, Kotlin 2.0.21. minSdk 26, 기존과 같은 targetSdk 34.

```sh
./gradlew testDebugUnitTest lintDebug assembleDebug
```

Android Studio에서 열거나 `ANDROID_HOME`/`local.properties`에 SDK 경로를 지정합니다.
결과: `app/build/outputs/apk/debug/app-debug.apk`.

## 구조와 제한

기존처럼 기본 Android Views를 사용하며 불필요한 UI/저장 라이브러리를 추가하지 않았습니다.
작은 기존 데이터 형식과의 연속성을 위해 이번에는 Room/DataStore로 바꾸지 않았습니다.
`TimerState`는 순수 Kotlin 상태 전이, `Store`는 저장, `TimerEngine`/`TimerReceiver`는 시스템 알람과 알림, `WallpaperRenderer`는 배경화면을 담당합니다.

강제 중지하면 시스템이 알람/수신을 차단하므로 앱을 다시 열어야 복구됩니다.
정확한 알람 권한을 거부하면 완료 알림이 지연될 수 있지만 다시 열 때 남은 시간은 저장된 종료 시각으로 계산됩니다.
알림 권한 및 잠금화면 내용 표시는 사용자의 시스템 설정에 따릅니다.
재부팅 후에는 BOOT_COMPLETED 수신 시 저장된 종료 시각으로 복원합니다. 기기 시각 변경도 해당 시각 기준으로 재예약합니다.
배경화면은 자동 복원하지 않으며 선택/시작 시 덮어씁니다(기존 동작).
잠금 해제 시 별도 화면을 띄우는 기능은 포함하지 않습니다.

정적 분석 결과와 실기기 점검표: [docs/APK_ANALYSIS.md](docs/APK_ANALYSIS.md).

체크리스트 항목의 이름을 길게 누른 뒤 위아래로 끌어 순서를 바꿀 수 있습니다. 순서는 분류별로 저장하며, 목록 밖에 놓아 취소하면 이전 순서를 유지합니다.
